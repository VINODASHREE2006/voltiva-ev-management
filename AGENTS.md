# Voltiva Project Instructions

## Security
- Never read, print, expose, or modify .env files.
- Never expose API keys, passwords, tokens, or credentials.
- Never hardcode secrets in source code.
- Never expose Supabase service-role keys in frontend code.
- Use existing environment variable names without revealing values.
- Never delete or recreate existing database tables without approval.

## Development
- Preserve the existing Voltiva UI and design.
- Use Next.js, TypeScript, Tailwind CSS and Supabase.
- Inspect existing code before modifying files.
- Test changes before considering a feature complete.
